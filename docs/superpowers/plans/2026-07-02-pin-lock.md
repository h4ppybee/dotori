# PIN 잠금 (넘버패드) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 잠금 화면을 6자리 숫자 PIN + 커스텀 넘버패드로 전환하고, 기존 문자 비밀번호 사용자는 설정에서 PIN으로 전환할 수 있게 한다.

**Architecture:** 새 UI 프리미티브(`NumberPad`, `PinDots`) + `Settings.lockType` 분기. 암호화 계층(`deriveKey`/`rekeyVault`)은 그대로 재사용하고 PIN 문자열을 secret으로 넘긴다. LockGate는 setup을 PIN 2회 입력 자동 진행으로 바꾸고, unlock은 lockType에 따라 PIN 넘버패드 / 기존 텍스트 입력으로 분기한다.

**Tech Stack:** Next.js 16(App Router, client), React 19, Tailwind v4(DESIGN.md 토큰), Dexie, vitest + Testing Library + fake-indexeddb.

**스펙:** [2026-07-02-pin-lock-design.md](../specs/2026-07-02-pin-lock-design.md)

**공통 명령:** `npm test -- <파일>` (단건), 마지막에 `npm run typecheck && npm run lint && npm test`.

동작 정의:

- unlock: `settings.lockType === "pin"`이면 PinDots+NumberPad, 6자리 차면 자동 검증. 실패 시 에러 + `pin` 초기화. 그 외(undefined 포함)는 기존 텍스트 폼 유지 + 안내 캡션 "설정에서 PIN으로 바꿀 수 있어요."(`text-[13px] text-muted`).
- 제출 중 NumberPad `disabled`. 도토리 아이콘 헤더·세션 자동 해제·useSessionGuard는 그대로.
