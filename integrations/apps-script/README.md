# dotori Apps Script (구글 시트 내보내기 · 기기 동기화)

시트 내보내기와 기기 동기화 저장소를 겸하는 웹앱입니다. dotori 앱이 자산·부채·통장 쪼개기를 구글 시트의 `dotori_*` 탭으로 보내거나, 암호화한 기기 동기화 데이터를 배포자 드라이브에 저장할 때 받습니다. 앱 쪽 계약은 `docs/external-api.md`의 "구글 시트 내보내기"·"기기 동기화"와 `docs/device-sync.md`를 참고하세요.

## 설치

1. 대상 시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 새 파일 `dotori-export.gs`를 만들고 `sheet-export.gs` 내용을 그대로 붙여넣습니다. 기존 스크립트(커스텀 함수 등)는 그대로 둡니다.
3. **프로젝트 설정 → 스크립트 속성**에 `DOTORI_SECRET`을 추가하고 충분히 긴 임의 문자열을 넣습니다.
   - 예: 터미널에서 `openssl rand -base64 24`
4. **배포 → 새 배포 → 유형: 웹앱**, 실행 계정 **나**, 액세스 **모든 사용자**로 배포하고 권한을 승인합니다.
5. 배포 URL(`https://script.google.com/macros/s/…/exec`)과 3번의 비밀키를 dotori **설정 → 구글 시트 내보내기**에 입력하고 "연결하기"를 누릅니다.

스크립트를 고친 뒤에는 **배포 관리 → 편집 → 버전: 새 버전**으로 다시 배포해야 반영됩니다(URL은 유지).

## 기기 동기화를 쓰려면 (기존 설치에서 업그레이드)

기기 동기화는 이 웹앱에 `sync.*` 액션을 더해, 앱이 암호화한 데이터를 **배포자 구글 드라이브의 `dotori-sync/` 폴더**에 저장합니다. 드라이브 권한이 새로 필요하므로 아래 순서로 다시 배포합니다.

1. Apps Script 편집기에서 `dotori-export.gs` 내용을 최신 `sheet-export.gs`로 통째로 바꿉니다.
2. 함수 선택 목록에서 **`authorizeDotoriSync`** 를 골라 **실행**하고, 드라이브 권한을 승인합니다. 드라이브 루트에 `dotori-sync` 폴더가 생깁니다.
3. **배포 → 배포 관리 → (기존 웹앱) 편집 → 버전: 새 버전 → 배포**. URL은 그대로라 앱 설정을 바꿀 필요가 없습니다.
4. dotori **설정 → 기기 동기화**에서 첫 기기는 "이 기기에서 처음 시작하기", 나머지 기기는 시트 내보내기를 같은 URL·비밀키로 연결한 뒤 "다른 기기에서 연결하기"에 동기화 키를 넣습니다.

- `dotori-sync/`에는 `current.json`(최신본)과 `v-<revision>.json`(최근 10개)이 쌓입니다. 내용은 암호문이라 드라이브에서 열어도 읽을 수 없습니다. 11번째 이전 버전은 휴지통으로 옮겨집니다.
- 스크립트 속성 `DOTORI_SYNC_META`(마지막 revision·저장 시각·기기 이름·keyId·버전 파일 id `fileId`)와 `DOTORI_SYNC_FOLDER_ID`는 스크립트가 직접 관리합니다. 손으로 고치지 마세요. 처음부터 다시 시작하려면 앱의 "새 키로 다시 시작하기"를 씁니다.
- 웹앱 URL·비밀키·동기화 키는 채팅·메모·저장소에 남기지 말고 기기에 직접 입력합니다.

## 기기 동기화 수동 확인 체크리스트

브라우저 두 개(예: 일반 창과 다른 브라우저 프로필)를 기기 A·B로 씁니다.

- [ ] 재배포 후에도 "지금 내보내기"가 그대로 동작한다(시트 내보내기 하위 호환)
- [ ] A "이 기기에서 처음 시작하기" → 키가 보이고, 드라이브 `dotori-sync/`에 `v-1.json`·`current.json`이 생긴다(첫 put)
- [ ] A에서 금액을 바꾸고 "지금 동기화하기" → `v-2.json`이 생긴다(revision 증가)
- [ ] B "다른 기기에서 연결하기" + A의 키 → A의 수동 데이터로 바뀐다. B의 API 연동·자동 자산은 그대로다
- [ ] B를 새로고침해 잠금 해제하면 A의 최신 변경을 받는다(잠금 해제 시 받기)
- [ ] A·B에서 서로 다른 값을 바꾸고 A만 먼저 동기화 → B "지금 동기화하기"에서 충돌 다이얼로그가 뜬다(CONFLICT)
- [ ] 충돌에서 "이 기기 내용으로 덮기" → 다른 쪽이 다음 잠금 해제·지금 동기화 때 그 내용을 받는다(force)
- [ ] A·B가 같은 값으로 바꾼 뒤 동기화하면 다이얼로그 없이 끝난다(자동 해소)
- [ ] B "새 키로 다시 시작하기" → A의 다음 동기화가 "동기화 키가 맞지 않아요"로 멈춘다(reset/KEY_MISMATCH). A에서 "동기화 끄기"를 누른 뒤 "다른 기기에서 연결하기"에 B의 새 키를 넣어야 풀린다(켜진 상태에서는 키만 바꿀 수 없다)
- [ ] 재배포 후 첫 올리기부터 `DOTORI_SYNC_META`에 `fileId`가 생기고, 받기는 그 id의 파일을 읽는다. `fileId`가 없는 예전 메타에서도 받기가 동작한다(이름으로 찾기)
- [ ] 메타가 가리키는 `v-*.json`을 휴지통으로 옮기면 받기가 "동기화 파일을 찾지 못했어요…"로 멈추고, 최신 내용이 있는 기기에서 "새 키로 다시 시작하기"로 복구된다
- [ ] 드라이브 휴지통에 `dotori-sync` 폴더가 있어도 휴지통 밖 폴더를 쓰거나 새로 만든다
- [ ] 12번 이상 동기화한 뒤 `v-*.json`이 10개만 남는다(오래된 버전 정리)
- [ ] 드라이브 휴지통에 이전 `v-*.json`이 남아 있어도 받기·올리기·정리가 정상 동작한다(휴지통 파일은 건너뛴다)
- [ ] 앱의 비밀키를 틀리게 저장하면 "비밀키가 스크립트 설정과 달라요"가 뜬다
- [ ] (선택) 터미널 확인: 값은 환경변수로만 넣는다 — `curl -sL -H "Content-Type: text/plain" -d "{\"action\":\"sync.meta\",\"secret\":\"$DOTORI_SECRET\"}" "$DOTORI_WEB_APP_URL"`

## 구글 시트 내보내기 수동 확인 체크리스트

- [ ] 설정에서 "지금 내보내기" → `dotori_자산`·`dotori_부채`·`dotori_통장쪼개기`·`dotori_meta` 탭이 생기고 채워진다
- [ ] 종목코드 `005930`이 `5930`이 아니라 `005930`으로 남는다
- [ ] 비고에 `=1+1`을 넣고 내보내면 수식이 아니라 문자열로 남는다
- [ ] 숫자 열(금액·수익률)이 숫자로 들어가 `SUM`이 된다. `General` 서식이 거부되면 `NUMBER_FORMAT`을 `"0.##########"`로 바꾼다
- [ ] 앱의 비밀키를 틀리게 저장하면 "비밀키가 스크립트 설정과 달라요"가 뜬다
- [ ] 항목을 지우고 다시 내보내면 남은 행 없이 줄어든다
